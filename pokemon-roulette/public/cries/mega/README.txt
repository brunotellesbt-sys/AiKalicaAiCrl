Optional Mega Cry Assets

This folder is intentionally empty.

If you have legal, properly licensed (public domain / CC0 / your own original) audio files,
you can place them here to override the synthetic cry used by the game.

Naming convention:
  public/cries/mega/<megaApiName>.ogg
  public/cries/mega/<megaApiName>.mp3
  public/cries/mega/<megaApiName>.wav

Examples:
  public/cries/mega/charizard-mega-x.ogg
  public/cries/mega/mewtwo-mega-y.mp3

If no matching file is found, the game will play a deterministic synthetic cry.
